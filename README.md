# 토스뱅크 리메이크

앱인토스 미니앱 컨테스트 제출용으로 만든 토스뱅크 홈·송금 화면 리메이크 웹앱입니다.
HTML 파일 하나(`index.html`)로 동작하며, 폰트·이미지·애니메이션이 모두 파일 안에 들어 있어 별도 설치나 빌드가 필요 없습니다.

## 실행 방법

### PC에서 보기
`index.html`을 브라우저로 열면 됩니다. 화면이 넓으면 390×844 크기의 폰 프레임 안에 표시됩니다.

### 휴대폰에서 보기 (같은 와이파이)
1. 이 폴더에서 로컬 서버를 실행합니다.
   ```
   python -m http.server 8000 --bind 0.0.0.0
   ```
2. 휴대폰을 PC와 같은 공유기에 연결하고 `http://<PC의 IP 주소>:8000/` 으로 접속합니다.
   - PC의 IP 주소는 `ipconfig`에서 확인할 수 있습니다 (예: 192.168.x.x).
   - 안 열리면 Windows 방화벽에서 Python을 허용하거나, 네트워크 프로필을 "개인"으로 바꿔 주세요.
3. 사파리 공유 메뉴에서 "홈 화면에 추가"를 하면 앱처럼 전체 화면으로 실행됩니다.

## 주요 기능

- **홈** – 계좌 목록과 잔액, 송금 버튼, 포인트 받기, 이번 달 쓴 돈, 추천 카드, 하단 탭바
- **계좌 상세** – 홈이나 자산 화면에서 계좌를 누르면 열립니다. 잔액, 채우기/보내기, 최근 보낸 내역, 이벤트 카드, 다른 계좌 목록
- **송금** – 받는 사람 선택 → 금액 입력(키패드) → 확인 → 완료
  - 보내기를 누르면 확인 화면이 그 자리에서 완료 화면으로 바뀝니다 (실제 토스 앱 녹화 영상 기준으로 타이밍을 맞춤)
  - 송금 완료 코인 애니메이션은 실제 화면 녹화로 만든 60fps 영상입니다 (다크·라이트 각각)
- **자산** – 총 자산, 계좌·포인트 탭
- **내역·알림** – 이 앱에서 보낸 송금 기록
- **전체 메뉴** – 화면 테마 선택, 계좌 이름·아이콘·잔액 편집, 받는 사람 편집, 처음 상태로 되돌리기

입력한 계좌와 송금 내역은 브라우저의 localStorage에 저장되며 실제 돈은 오가지 않습니다.

## 화면 테마

- 처음에는 휴대폰의 시스템 설정(라이트/다크)을 따릅니다.
- **전체 → 화면 테마**에서 시스템 설정 / 라이트 / 다크를 직접 고를 수 있고, 선택은 저장됩니다.
- 색상은 CSS 변수로 관리합니다. 다크 값은 `:root`, 라이트 값은 `html.lt`에 있습니다. 새 색을 추가할 때는 두 곳에 모두 넣어 주세요.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체 (HTML·CSS·JS, 폰트·이미지·영상 포함, 약 1.5MB) |
| `apple-touch-icon.png` | 홈 화면에 추가할 때 쓰는 아이콘 |
| `토스뱅크 리메이크 (… 백업).html` | 작업 단계별 백업 파일 |

## 코드 구조 (index.html)

- `SCR` – 화면별 템플릿 함수 (`home`, `send`, `amount`, `confirm`, `done`, `menu`, `assets`, `hist`, `noti`, `acct`)
- `IDS` – 화면 순서. 화면 전환은 `push` / `back` / `tab` 함수가 담당합니다.
- `S` – 저장되는 앱 상태 (계좌, 받는 사람, 송금 내역 등). `DEF()`가 기본값입니다.
- `sendFlow` – 보내기 버튼을 누른 뒤의 송금 연출 타이밍
- `CVD` / `CVL` – 송금 완료 코인 애니메이션 영상 (다크 / 라이트)

## 참고

- 아이폰 홈 화면 앱(iOS 26 이상)에서는 상태바 아래가 살짝 흐리게 보일 수 있습니다. iOS 시스템이 그리는 효과라 코드로 끌 수 없으며, 토스 앱 안(앱인토스)에서는 나타나지 않습니다.
- 토스, 토스뱅크의 이름과 로고는 해당 회사의 상표이며, 이 프로젝트는 컨테스트 제출용 리메이크입니다.
